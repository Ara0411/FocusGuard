# 🛡️ FocusGuard
> **Npcap 기반 실시간 패킷 필터링을 이용한 하이브리드 학습 집중 관리 플랫폼**

FocusGuard는 브라우저 시크릿 모드나 확장 프로그램 무력화 등 기존 소프트웨어 방식 차단 앱의 우회 한계를 극복하기 위해, **네트워크 하부 계층 트래픽 제어** 기술을 채택한 강력한 학습 몰입 지원 애플리케이션입니다. C++ 백그라운드 분석 엔진과 가벼운 내장 웹 서버를 결합하여 사용자에게 직관적이고 세련된 대시보드를 제공합니다.

---

## 🛠️ Technology Stack (기술 스택)

| 분류 | 기술 기술 / 라이브러리 | 상세 역할 |
| :--- | :--- | :--- |
| **OS** | Windows 10 / 11 | Npcap 드라이버 및 시스템 트레이 구동 환경 |
| **Language** | C++17 이상 | 고성능 백그라운드 제어 엔진 구현 |
| **Network SDK** | Npcap SDK | 로우 레벨 패킷 캡처 및 L7 SNI 필드 기반 실시간 도메인 식별 |
| **Backend / Server** | cpp-httplib | 임베딩 형태의 경량 로컬 웹 서버 구동 및 프론트엔드 API 서빙 |
| **Frontend** | HTML5 / CSS3 / JavaScript | 학습 현황 대시보드 UI 및 차단 설정 웹 인터페이스 구현 |
| **Agent Framework** | Qt 6 | 시스템 트레이(Tray) 상주형 백그라운드 에이전트 프로세스 관리 |
| **Data Management** | JSON / CSV (Local) | 파일 기반 로컬 데이터 저장 및 학습 통계 영속화 관리 |

## 👥 Members & Roles (업무 분장)

본 프로젝트는 팀장(PM)의 전체 조율 하에 개발 파트 3인과 지원 파트 1인의 철저한 분업 시스템 체계로 개발됩니다.

* **최아라**: 프로젝트 매니징(PM) 및 시스템 아키텍처 설계, 요구사항 정의 및 기능 명세서 확정, 개발 모듈 간 통합 프로세스 관리 및 최종 업로드/발표 총괄
* **신승훈**: 네트워크 보안 로직 구현 (Npcap 기반 실시간 패킷 캡처, TLS Client Hello 내 SNI 필드 추출 알고리즘 및 TCP RST를 이용한 세션 차단 기술 엔진 개발)
* **김진우**: 웹 프론트엔드 및 대시보드 개발 (HTML/CSS/JS 기반 대시보드 UI 설계, 차단 사이트 관리 페이지 구현 및 실시간 학습 통계 데이터 시각화)
* **정기주**: 시스템 연동 및 백그라운드 서버 개발 (cpp-httplib 기반 로컬 웹 서버 구축, Qt 6 기반 시스템 트레이 에이전트 구현 및 에이전트 실행 시 기본 브라우저 자동 호출 로직 담당)
* **김민서**: 품질 보증(QA) 및 기술 리서치, 국내외 차단 우회 기법 동향 조사, 발표 자료 및 시연 영상 제작, 환경별 테스트 케이스 작성 및 구동 전수 검증
